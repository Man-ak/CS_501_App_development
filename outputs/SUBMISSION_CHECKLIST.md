# Mobility Lens submission checklist

- [ ] Open this folder in Android Studio Quail 4 Feature Drop.
- [ ] Let Gradle sync, then run the app on your assigned emulator.
- [ ] Capture the first dimension: Input and interaction.
- [ ] Tap Next; enter a feature name; capture a different dimension with the successful feedback message.
- [ ] Clear the field; tap Consider this dimension; capture the blank-field message.
- [ ] Enter a name again; tap Consider this dimension; capture the successful message.
- [ ] Rotate after navigating and entering text. Record exactly what resets in the PDF report draft.
- [ ] Replace the bracketed identity, emulator, and rotation fields in the report, then revise it in your own words.
- [ ] Add the AI disclosure below and any actual collaboration details.
- [ ] Initialize a Git repository, commit source files only, and add the repository link to the submission.
